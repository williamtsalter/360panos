How these panoramas were made

155
raw DNG frames per site
535 MP
stitched panorama (Site 2)
32,716 × 16,358
pixels, equirectangular (Site 2)
98 MB
streamed tile set, 6 zoom levels (Site 2)
  1. Capture. A DJI Mavic 4 Pro hovered at each site in sphere panorama mode, using the 2X camera. It took 155 overlapping raw frames. The narrower lens needs more frames but gives much finer detail.
  2. Stitching. The frames were stitched into one equirectangular panorama in Panovolo 1.12.1.
  3. Tiling. Each panorama was reprojected onto a cube with Hugin's nona, then cut into 512 pixel tiles with Pannellum's multiresolution generator.
  4. Viewing. Pannellum loads only the tiles you are looking at, so a huge image opens quickly on a laptop or phone.

Full methods, code and references are in the GitHub repository.

Software

  • Panovolo for stitching
  • Hugin for cube map reprojection
  • Pannellum by Matthew Petroff, the open source viewer (Petroff 2019, JOSS)
  • GitHub Pages for free hosting
